The **Employee** section allows administrators to view, search, filter, and onboard individual staff members or batch-import employee records across assigned office locations.

---

## Employee Directory Overview

{/*  IMAGE PLACEHOLDER 1: Main Employee Management Table View  */}

![Screenshot 2026 09 01 083141](/images/Screenshot-2026-09-01-083141.png "Screenshot 2026 09 01 083141")

The main employee table lists all registered staff alongside their current clock status, personal information, work schedule, role designation, and account creation date.

### Directory Columns

| Column | Description |
| :-- | :-- |
| **Clock** | Current punch status (e.g., `Clock In`, `Clock Out`). |
| **Full Name** | First and last name of the employee. |
| **Gender** | Specified gender identity. |
| **Phone** | Registered contact phone number. |
| **Status** | Employment status badge (e.g., `Active`). |
| **Shift** | Assigned working shift times (e.g., `morning 07:30 - 17:00`). |
| **Designation** | Job title or permission level (e.g., `AGENT`, `ADMIN`). |
| **Email Address** | Primary work/contact email address. |
| **Created At** | Timestamp when the profile was added. |
| **Action** | View details icon (eye symbol) to inspect profile records. |

## Adding Single Employees

{/*  IMAGE PLACEHOLDER 2: Register Employee Modal Form  */}

![Screenshot 2026 09 01 083202](/images/Screenshot-2026-09-01-083202.png "Screenshot 2026 09 01 083202")

Click the **Add Employee** button to register individual staff members manually. Complete the required fields in the registration modal:

1. **Full Name:** Enter the employee's legal name.
2. **Mobile Number:** Enter primary phone details.
3. **Email Address:** Enter standard contact email.
4. **Role:** Select job permissions (e.g., `AGENT`, `ADMIN`).
5. **Gender:** Select gender identity.
6. **Office:** Assign employee to a designated office location.
7. Click **Create Employee** to finalize registration.

## Bulk Uploading Employees

{/*  IMAGE PLACEHOLDER 3: Bulk Upload Employees CSV Modal  */}

![Screenshot 2026 09 01 083147 1](/images/Screenshot-2026-09-01-083147-1.png "Screenshot 2026 09 01 083147 1")

To register multiple employees simultaneously, click the **Bulk Upload** button:

1. **Select Office Location:** Choose the target location for all employees in the upload batch.
2. **Download CSV Template:** Click **Download CSV** to acquire the pre-formatted structure required for error-free parsing.
3. **Upload File:** Drag and drop your completed spreadsheet file into the upload zone or click **browse** (Supports `CSV`, `XLSX`, and `XLS` file formats).
4. Click **Upload File** to import all listed personnel.

## Filtering and Searching

{/*  IMAGE PLACEHOLDER 4: Employee Filter Panel Popup  */}

![Screenshot 2026 09 01 083210](/images/Screenshot-2026-09-01-083210.png "Screenshot 2026 09 01 083210")

- **Search Input:** Type an employee's name or details into the search bar to locate specific records.
- **Location Dropdown:** Quick-filter records across all offices or select a specific branch.
- **Filter Panel:** Click **Filter** on the top right to open advanced query options:
  - **Start Date / End Date:** Filter records created within a specific timeframe.
  - **Limit:** Restrict the maximum number of results displayed per page.
  - Click **Filters** to apply choices.
