The **Leave** section allows administrators to review, approve, or reject employee time-off applications across their assigned office locations.

Administrators can track employee leave applications directly from the **Leave Requests** dashboard table.

### Directory Fields & Actions

| Field | Description |
| :-- | :-- |
| **Search Input** | Search entries by typing an employee's name in the `Search employee...` field. |
| **Employee** | Full name of the employee submitting the leave request. |
| **Email** | Work email address of the requesting employee. |
| **Leave Type** | Category of leave requested (e.g., _Annual Leave_, _Sick Leave_, _Casual Leave_). |
| **Start / End** | Start and end dates defining the requested leave duration. |
| **Reason** | Note or explanation provided by the employee for their leave application. |
| **Status** | Current approval state of the request (e.g., `Pending`, `Approved`, `Declined`). |
| **Action** | Options for administrators to **Grant** or **Decline** the submission. |

---

## Reviewing Leave Requests

1. Navigate to the **Leave** tab on the side navigation menu.
2. Locate the employee's request using the directory table or search bar.
3. **Approve Request:** Click **Grant** to approve the leave submission.
4. **Decline Request:** Click **Decline** to reject the submission. A prompt will appear requiring you to enter a **Reason for Decline** to provide context back to the employee before finalizing the rejection.
